# Addis Eats - Authentic Ethiopian Restaurant App

Live Deployed URL: https://addis-eats.vercel.app

## Project Overview
Addis Eats is a full-stack Next.js application designed for restaurant menu browsing, dynamic dish rendering, and order management. Built for the IBT College Frontend Capstone.

## Local Setup Instructions
1. Clone repository: `git clone <repo-url>`
2. Install dependencies: `npm install`
3. Start development server: `npm run dev`
4. Open `http://localhost:3000`

## Tech Stack
Next.js (App Router), React, JavaScript, Context API, CSS Modules.
